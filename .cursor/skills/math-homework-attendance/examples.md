# 示例

## 示例 1：用户发来某日完整名单（含家长/昵称行）

**输入含义**：名单里可能出现 `李鸿宇妈妈15392872081`、`陈子屹`、`达达` 等。

**处理**：

- `李鸿宇妈妈` → 花名册 **李鸿宇**
- `陈子屹` → 若班级约定对应 **陈语萌**，在 `mapping_notes` 写「陈子屹→陈语萌」
- `达达` → 用户若说明为 **谢泓达**，写入 `present` 为 **谢泓达**，并在 `mapping_notes` 记「达达→谢泓达」

**不要**把「李鸿宇妈妈」原样写入 `present`。

## 示例 2：汇报打卡人数

用户问：「4.19 多少人打卡？」

**回答结构**：

1. **HTML / 花名册维度**：`len(present)`（表中 🏆 人数）。
2. 若 `app_completed_count` 与上不同：说明 App 显示人数及原因（例如有昵称未进花名册，或已全部映射后两数应一致）。

```bash
python3 build_attendance_grid.py
```
